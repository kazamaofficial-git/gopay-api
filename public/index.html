Memeriksa server

Terima bayar GoPay lewat satu API.

Cetak QRIS dinamis dengan nominal tepat, cek pembayaran yang masuk, dan beri pembeli halaman bayar siap pakai. Berjalan di server kamu sendiri, tanpa pihak ketiga.

QRIS

Cetak QRIS dinamis

Ubah QRIS statis GoBiz jadi QRIS dengan nominal sendiri. Dibuat lokal di server, lengkap dengan checksum CRC16 sesuai standar EMVCo.

5405250005802ID...6304A1F9
Verifikasi

Cek pembayaran masuk

Cocokkan nominal dan waktu transaksi. Satu transaksi hanya bisa diklaim satu trx_id, jadi dua pembeli tidak saling mengambil pembayaran.

{ "paid": true, "amount": 25000 }
Pembeli

Halaman bayar

Kirim link /qr/:id. Ada hitung mundur 5 menit dan cek otomatis.

Laporan

Riwayat mutasi

Ambil transaksi QRIS, GoPay, dan kartu dalam rentang waktu pilihanmu.

Keamanan

Aman sejak awal

API key dibandingkan timing-safe, endpoint publik dibatasi, QR dibuat lokal.

Alur integrasi

Empat langkah dari pesanan sampai lunas.

1

Buat QRIS

Backend memanggil /create-qris dan menyimpan trx_id.

2

Kirim link bayar

Pembeli membuka qris_url lalu scan dari aplikasi apa pun.

3

Cek status

Backend memanggil /check-payment dengan nominal dan trx_id.

4

Tandai lunas

Saat paid bernilai true, pesanan kamu proses.

Dokumentasi lengkap, langsung di web

Semua parameter, contoh respon, contoh kode untuk Node.js, PHP, dan Python, sampai panduan deploy ada di satu halaman.

Buka dokumentasi
